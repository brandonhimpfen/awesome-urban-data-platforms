Urban data platforms provide the infrastructure to collect, standardize, store, and distribute city data streams across municipal departments, public agencies, and citizens. This list is intended for smart city architects, municipal data engineers, open data managers, urban planners, and civic tech developers.

## Municipal Open Data Portals

Open-source platform engines, catalog management software, and portal frameworks for publishing public city datasets.

- [CKAN](https://github.com/ckan/ckan) — The open-source data portal software used by governments and municipal entities worldwide to power public data repositories.
- [DKAN](https://github.com/GetDKAN/dkan) — Open-source open data platform built on Drupal, providing dataset management and public API generation.
- [OpenDataSoft Core Framework](https://www.opendatasoft.com/) — Cloud platform engine engineered for publishing, sharing, and visualizing municipal open data feeds.
- [Magda](https://github.com/magda-io/magda) — Federated open-data catalog framework for searching, managing, and indexing distributed public sector data stores.

## City Data Integration & Ingestion

Middleware, ETL pipelines, and context management components for ingesting municipal sensor feeds and administrative records.

- [FIWARE Context Broker (Orion-LD)](https://github.com/FIWARE/context.Orion-LD) — OGC NGSI-LD compliant context broker for managing real-time urban context data and linked entities.
- [Apache NiFi Urban Templates](https://github.com/apache/nifi) — Automated data flow templates for ingesting high-volume municipal sensor streams and agency feeds.
- [Urban-Data-Pipeline-Kit](https://github.com/smart-cities-data) — Python-based ETL frameworks for transforming raw municipal data into standardized open schemas.

## Urban Data Governance & Privacy

Frameworks, policy engines, and data protection software built to enforce municipal privacy standards and secure open data releases.

- [Open-Data-Privacy-Toolkit](https://github.com/governance-data) — Guidelines and automated tools for applying $k$-anonymity and differential privacy to municipal releases.
- [Consent-Management-Engine](https://github.com/civic-tech) — Open framework for managing public data collection consent and citizen privacy preferences.
- [Municipal Data Governance Schema](https://github.com/smartcity-governance) — Open templates for defining data stewardship, metadata standards, and access control levels in city systems.

## Civic Analytics & Visualization

Visualization toolkits, geospatial analytical dashboards, and public reporting portals built on urban data feeds.

### Open Analytics Dashboards

- [Kepler.gl](https://github.com/keplergl/kepler.gl) — Data-agnostic, WebGL-empowered geospatial analysis tool for large-scale urban movement and location dataset visualization.
- [City-Dashboard-Core](https://github.com/civic-analytics) — Open-source web application for aggregating city KPIs, public transport status, and municipal operational metrics.

### Spatial Data Catalogs

- [GeoNode](https://github.com/GeoNode/geonode) — Open-source geospatial content management system for sharing spatial data, layers, and interactive maps across municipal departments.
